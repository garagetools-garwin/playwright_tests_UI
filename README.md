1) Авторизация сейчас происходит в тесте "Переход в чек аут" в джобе с основными тестами
2) Файл авторизации сохраняется отдельно и хранится в кеше
3) Основная часть тестов и тест на создание заказов это две разные джобы
4) Если файл авторизации протух и джоба с тестам на заказ стартанула первой, она упадет, потому что в ней нет авторизации
5) Основной воркфлоу - это .github/workflows/playwright_order.yml
6) По скольку мы имеем две джобы test и order-test нельзя забывать, что для каждой из них секреты в воркфлоу пишутся отдельно. Если добавить секретт в начале воркфлоу, он будет применим только к джобе test, чтобы он был применим к order-test, требеутся продупблировать его перед джобой order-test. 
7) В тесте на создание заказа, значения в проверяемом json захардкожены, могут падать при изменении цены тестируемого товара. Для теста был взят наиболее простой товар со стабильной ценой за 4р.
